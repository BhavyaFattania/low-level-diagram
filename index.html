1. Domain Layer (pure business objects — no FastAPI / no DB)

Dataclasses. Candidate 1—* CandidateResponse, CandidateProfile 1—* QuestionEvaluation, Interview → InterviewStatus.

2. Persistence Layer (SQLAlchemy ORM + Repository pattern)

All ORM models inherit Base(DeclarativeBase). Each domain type has an ABC repository + InMemory (tests) + SA (SQLAlchemy) implementation. FK chain: Candidate → Interview → Response → Evaluation; Interview → Report.

3. Evaluation Engine (Strategy + LLM abstraction)

SimilarityStrategy is the Strategy port (TF-IDF / Embedding interchangeable). LLMClient is the Adapter port (Mock / OpenAI). EvaluationService orchestrates all six sub-evaluators.

5. API + Schemas (Pydantic boundary — isolated from domain by design)

Routers are thin adapters: validate Pydantic schema → call service → map domain to response schema. SubmitAnswerResponse ∘— EvaluationScores, EvaluationRead ∘— EvaluationScores, StartInterviewResponse ∘— QuestionPublic.
